# Curriculum and fixture coherence

The authoritative topic order is `course-index.json`, copied from the saved 119-lesson course. Each lesson directory retains its objective, core and practice/evidence brief. Changing the repository is not permission to change lecture narration or invent recorded outcomes.

Stage 3’s fixture-design sheet, Stage 3’s tool-stub example, Stage 6’s printer injection and Stage 20’s runner layout are separate synthetic teaching examples. Their different identifiers and ticket subjects are intentional; keep each example internally consistent. The default local runner uses Stage 20’s inventory and the T-104 stub contract. Stage 6’s printer worksheets are not silently substituted for that billing-receipt case.

Blank worksheets are learner-owned evidence templates, not completed results. The local runner supplies trace mechanics and bounded proposal replay; it does not supply an unspecified course scoring rubric, an autonomous model or a live HarborDesk UI. A course screen should show either genuine local output with its scope or an explicitly blank/proposed worksheet, never invented successful runs.

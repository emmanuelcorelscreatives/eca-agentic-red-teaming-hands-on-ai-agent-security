# Offline containment canvases

Stage 17, lesson 5: Independent Checks and Containment.

Open `data-scope.html` or `tool-scope.html` directly in a desktop browser. The reference captures use Microsoft Edge in English/light mode on Windows 11 24H2. These files need no server, sign-in, scripts, external assets or network access.

The data-scope illustration keeps the abstract agent and task-relevant records inside a fixed authorized-data boundary. The peer message points toward unrelated synthetic records outside that boundary; it does not move the boundary.

The tool-scope illustration gives each abstract agent a separate set of permitted capabilities. A requested cross-boundary invocation stops at the boundary. The diagram does not name a real tool integration or claim that HarborDesk executed or denied a call.

These are locally authored, static instructional diagrams, not HarborDesk application screens or observed test results. Use authorized lab evidence to establish which controls your actual environment enforces. Preserve the legitimate task and its required independent lookup when choosing limits.

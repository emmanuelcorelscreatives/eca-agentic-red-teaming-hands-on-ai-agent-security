# Conditional evidence categories

Stage 23, lesson 5 uses this author-built teaching slide to keep four categories separate: Observed, Proposed, Executed, and Durable synthetic state. The fifth box labels an unsupported assumption. No supplied HarborDesk trace, completed intervention, or real customer case is represented.

Open `HarborDesk-conditional-categories.fodp` in LibreOffice Impress 24.2 and start the slideshow with F5. The matching `evidence-categories.svg` is the vector source. This is a conditional priority-change example, not proof that any action occurred. Assess each category against independently collected evidence; a tool invocation does not establish a durable change.

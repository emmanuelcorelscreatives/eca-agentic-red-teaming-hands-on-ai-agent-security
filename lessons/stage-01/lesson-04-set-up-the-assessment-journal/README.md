## Saved lesson brief

Lesson 4 — Set Up the Assessment Journal
Stage 1 — Course Orientation and Rules of Engagement
Objective: Record a repeatable experiment without conflating observations and interpretations.
Core: Use a consistent template: authorized user goal, attacker objective, controlled surface, preconditions, intervention, run ID, observed events, conclusion, and limitations.
Practice / evidence: Document a harmless toy case and separate a model's stated intention from an actually executed tool action.

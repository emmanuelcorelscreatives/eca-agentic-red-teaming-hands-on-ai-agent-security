## Saved lesson brief

Lesson 5 — Safety Controls and Failure Recovery
Stage 3 — Building the Safe HarborDesk Lab
Objective: Stop runaway loops and recover safely from test failures.
Core: Configure step caps, action limits, rate or cost budgets, local-only egress, kill switch, cleanup, and per-run state namespaces. Rejected actions should still be visible in telemetry.
Practice / evidence: Trigger a benign loop-limit test; save the termination event and prove the sandbox can be reset.

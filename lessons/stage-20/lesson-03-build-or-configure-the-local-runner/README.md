## Saved lesson brief

Lesson 3 — Build or Configure the Local Runner
Stage 20 — Evaluation Harness, Replay, and Evidence Collection
Objective: Execute clean and adversarial cases through one repeatable interface.
Core: Configure a runner to load versioned fixtures, attach a case ID, enforce time and step caps, save traces, and clean up. Tool choice is implementation-neutral; an equivalent documented harness is acceptable.
Practice / evidence: Replay one ticket-injection case with the same scoring rules.

# Propagation and Cascade Metrics

Emmanuel Corels Academy · Stage 21, lesson 3

## Saved lesson brief

Lesson 3 — Propagation and Cascade Metrics
Stage 21 — Measuring Single-Turn Versus Cascading Failure
Objective: Measure severity beyond a single bad turn.
Core: Track first compromised step, number of subsequent affected decisions, distinct agents influenced, tool actions executed, sessions crossed, and time or steps to detection. Define cascade in advance: in this course, an initial compromise plus at least one consequential downstream propagation event.
Practice / evidence: Score two traces and show why only one meets the cascade definition.

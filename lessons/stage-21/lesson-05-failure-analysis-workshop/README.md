Lesson 5 — Failure Analysis Workshop
Stage 21 — Measuring Single-Turn Versus Cascading Failure
Objective: Turn metrics into an explanatory account of what failed.
Core: Trace source → decision → attempted action → gateway outcome → state change → downstream effects. Rank root causes by their ability to prevent further propagation.
Practice / evidence: Present one single-step case and one cascade case with evidence-backed conclusions.

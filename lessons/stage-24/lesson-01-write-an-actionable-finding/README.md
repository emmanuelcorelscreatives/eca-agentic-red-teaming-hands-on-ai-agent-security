Lesson 1 — Write an Actionable Finding

Objective: Express a verified failure without exaggeration.
Core: Include title, affected workflow, permitted attacker control, prerequisite, reproduction steps inside the lab, observed result, expected invariant, evidence, impact, and limitations.
